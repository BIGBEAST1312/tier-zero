# AI use disclosure

The course permits AI assistance provided it is disclosed. This file is the
team's running record; it is included in every deliverable.

## Comment format used in code

```python
# Generated with [tool], reviewed and modified by [name] (YYYY-MM-DD).
# Changed: [what you actually changed]
```

The "reviewed and modified by" half matters more than the "generated with" half:
it records that a person understood the code and took responsibility for it.

## What we did not delegate

Each team member can explain their own epic's code line by line, because the
product walkthrough and the weekly scrums require it. Where AI drafted something,
the owner rewrote or reviewed it before it was committed.
