# docs/

Working documents for the course deliverables. The submitted versions live in the
GitLab wiki; these are the drafts and supporting material.

- `ai-usage.md` — running AI disclosure record, included in every deliverable
- `gathering-content.md` — how the knowledge base gets built
- `hosting.md` — deployment options and what breaks when hosted
- `survey.md` — the requirements survey
- `data-model.md` — conceptual data model

Once a deliverable is submitted, do not edit its artifacts. Copy them into the
next deliverable's folder and edit the copy — the course requires previous
deliverables to stay visible in the portfolio.
